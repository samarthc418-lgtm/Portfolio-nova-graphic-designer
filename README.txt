# Samarth — Graphic Designer Portfolio

## Quick start
1. Unzip the folder.
2. Open `index.html` in a browser.
3. Replace the sample project artwork with your own images/content.

## Customize
- Main page: `index.html`
- Styling: `css/style.css`
- Interactions: `js/script.js`
- Your images: put them inside `images/`

## Important edits in index.html
- Change `Samarth` to your preferred name/brand.
- Change `your@email.com` to your real contact email.
- Update the Instagram and LinkedIn links.
- Replace sample project blocks with your actual work.

No build tools or server are required for this version.
